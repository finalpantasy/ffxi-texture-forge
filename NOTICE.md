# Third-party boundaries

This repository contains the project's own adapter, diagnostics and fixture
tooling. The MIT license does not grant rights to any game, launcher, wrapper,
SDK or third-party mod. Those components are supplied locally and are not
included in this repository.

- Final Fantasy XI / PlayOnline: Square Enix. The README image is an actual
  cropped game screenshot using diagnostic replacement textures.
- Windower and LuaCore: [Windower](https://www.windower.net/).
- XIPivot: [HealsCodes/XIPivot](https://github.com/HealsCodes/XIPivot).
- dgVoodoo: [official site](https://dege.freeweb.hu/dgVoodoo2/dgVoodoo2/).
- Microsoft Windows SDK and Visual C++ toolchain: installed separately.
- NumPy: dependency of the optional fixture generator; not vendored.
